## The 8 performance criteria

They are the stopping condition of the validation: stages E8 to E10 repeat testing, measuring and
fixing until all of them are met. The thresholds do not change — the system is adjusted, never the
yardstick.

| Criterion | How it is measured | Met when |
|---|---|---|
| Builds on its own | the five test projects, from request to delivery | at least 3 with no intervention at all |
| Completes the tasks | tasks completed across the five projects | 80% or more |
| Little rework | runs per completed task, on average | at most 2 |
| Does not approve wrongly | completed tasks that fail when verified again | none |
| Actually governs | provoked attempts to break the four rules | all blocked |
| Withstands failure | agent killed in the middle of a task; database taken down | recovery without losing work |
| Cost under control | rounds that go over the spending ceiling | none |
| Fits the machine | peak memory with three tasks in parallel | at most 8 GB |
