# FAB-403.3 · The implicit suite does not run twice

> ✅ Done · Subtask of FAB-403 · Stage **E4 — Task production line**

## The idea

Run the test suite once per verification, even when the task asks for the whole battery, which already includes the suite.

## What was done

`_management/ci.json` gained the `includes_suite` field, with the commands that already run the suite inside them (`mix factory.ci` and `mix factory.ci --fast`). `Factory.Criteria.Suite.append/2` does not append the implicit suite when any task criterion uses one of those commands, comparing by the same command key used for deduplication.

## Why it came up

Deduplication only merges identical commands. `mix test` (implicit) and `mix factory.ci` (declared) are different commands, so the suite ran twice in the same verification.

## How it was built

- A missing field, invalid JSON or a list with a non-text element become an empty list, i.e. the previous behaviour
- A malformed list is invalid as a whole, so the suite is never skipped only partially
- Comparison by `command_key/1`, which normalises `.bat`/`.exe` and `npm run`

## Acceptance criteria

- [x] A criterion with a command listed in `includes_suite` skips the implicit suite
- [x] A criterion with another command keeps the implicit suite
- [x] A missing or malformed field keeps the previous behaviour, without error
