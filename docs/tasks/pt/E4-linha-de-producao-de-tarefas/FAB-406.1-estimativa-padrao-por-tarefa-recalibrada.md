# FAB-406.1 · Estimativa padrão por tarefa recalibrada

> ✅ Concluída · Subtarefa de FAB-406 · Etapa **E4 — Linha de produção de tarefas**

## A ideia

Deixar a estimativa padrão do teto de gasto mais próxima do custo real de uma tarefa inteira, para o teto não subestimar a próxima tarefa.

## O que foi feito

`Factory.Budget` passou a declarar um novo valor de partida para a estimativa por tarefa concluída, usado enquanto a rodada ainda não mediu nada. A documentação e o doctest acompanham o novo valor.

## Por que surgiu

A estimativa se calibra sozinha com a média medida por tarefa concluída, mas o valor de partida decide as primeiras tarefas de uma rodada. Um valor de partida baixo deixa o teto aceitar uma tarefa que não cabe nele; o valor foi recalibrado para refletir o custo de uma tarefa inteira.

## Como foi feito

- `@default_estimate` recalibrado em `Factory.Budget`; a fórmula e o comportamento do teto não mudam
- Doctest de `estimate_next_task([])` e teste de `default_estimate/0` atualizados

## Critérios de aceite

- [x] Sem medição, a estimativa da próxima tarefa é o valor declarado
- [x] Com medições, a média medida continua mandando
